# AI Renovation Platform — прототип

Этап 1: скелет веб-приложения и мастер создания проекта (шаги 0–7 из документа
«Вопросы клиенту и путь пользователя»).

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # тесты доменной логики
npm run typecheck  # проверка типов во всех пакетах
npm run build      # production-сборка веба
```

## Структура

```
packages/domain/   Доменная модель и бизнес-правила (чистый TypeScript, без UI).
                   Переиспользуется в будущем мобильном приложении.
  types.ts         Проект, геометрия плана, стены, жильцы, пожелания
  walls.ts         Статусы стен: подсказки по толщине, запрет сноса несущих/неизвестных
  wizard.ts        Шаги мастера, обязательные поля, шкала точности
apps/web/          Веб-приложение: React + Vite + Ant Design + Zustand
  features/wizard/ Мастер и его шаги
  features/plan/   2D-отрисовка плана (SVG) из геометрии
  store/           Состояние (сейчас localStorage, далее — API)
  demo/            Демо-план для прототипа (до подключения распознавания)
```

## Что работает и что нет

Работает: все 9 шагов мастера, ветки вопросов по цели, разметка стен кистью,
инженерные точки на плане, шкала точности, сохранение и просмотр проектов.

Шаг «Отделка» (по созвону 09.11.2026, `docs/meeting-2026-11-09-finishes.md`): выбор по каждой комнате
карточками-картинками — потолок, освещение, стены, пол, двери, сантехника, мебель, шторы; розетки и
светильники для всей квартиры. Правила в `packages/domain/src/finishes.ts`: санузел — стены краска/плитка,
пол только плитка; классика — только двери с наличниками и рамки на стенах; шторы — только в комнатах
с окнами; копирование отделки из другой комнаты. Иллюстрации на карточках — схемы, не фото материалов.

Не реализовано (честно помечено в интерфейсе):
- распознавание загруженного плана — используется **демо-план**;
- бэкенд и аккаунты — данные хранятся только в браузере (localStorage);
- генерация вариантов, 3D, смета, ручной редактор плана.

Пороги толщины стен и веса шкалы точности — гипотезы, их нужно уточнить.
